# Skills Demonstrated

## Project

AI Road Hazard Detection System

## Core Technical Skills

### Artificial Intelligence / Computer Vision
- YOLOv8 integration using `ultralytics`
- Bounding box extraction and detection result processing
- OpenCV-based video frame handling
- AI-assisted hazard detection workflow design

### Backend Engineering
- FastAPI API design and implementation
- Multipart media upload handling
- REST endpoint design for reports and analytics
- Async database access with SQLAlchemy
- Config-driven backend deployment

### Frontend Engineering
- React + TypeScript UI development
- Component-based dashboard implementation
- API integration with async fetch patterns
- State handling for upload, map, and analytics views
- Responsive interface design for demo-ready presentation

### Data and Persistence
- Relational schema design for media, reports, and detections
- SQLite integration for MVP persistence
- Query design for summary analytics and heatmap data
- Easy migration path toward PostgreSQL

### Geospatial / Mapping
- Leaflet integration
- Hazard coordinate mapping
- Marker rendering and popup design
- Heat overlay generation from stored hazard data
- Base architecture ready for MapmyIndia integration

### Deployment / DevOps
- Dockerizing FastAPI backend
- Vercel deployment setup for frontend
- Render-ready backend container configuration
- Environment-variable based configuration
- Cross-origin deployment setup with frontend/backend separation
